## Initial failures resolved

Prisma's initial engine/checksum download returned a cloud egress HTTP 403. Required official network domains were added to the draft. Clean installation later downloaded the engines and generated the client successfully, with verification retained. The initial full test attempt failed before API collection; the later complete run executed and passed all 39 tests.

Old pinned Vite/Vitest releases had audit advisories. They were replaced by tested current releases; the final audit reported none.

The cloud Docker build needed a writable Docker configuration directory and explicit routing through the provided proxy plus the provided trusted CA as a temporary BuildKit secret mount. The image built successfully without disabling TLS/checksum verification or baking the CA mount into the image. Initial non-root startup then exposed restrictive ownership on copied workspace files; `COPY --chown=node:node` corrected it, and the subsequent production container checks passed. These are local cloud-builder constraints, not evidence of Railway deployment failure.
